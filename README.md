# QR-sidor

GitHub Pages-sidor för användaren `oskarturewinberg`.

När repositoryt heter `qr-sidor` och GitHub Pages är aktiverat blir adresserna:

- Sida 1: https://oskarturewinberg.github.io/qr-sidor/sida1/
- Sida 2: https://oskarturewinberg.github.io/qr-sidor/sida2/
- Sida 3: https://oskarturewinberg.github.io/qr-sidor/sida3/
- Sida 4: https://oskarturewinberg.github.io/qr-sidor/sida4/
- Sida 5: https://oskarturewinberg.github.io/qr-sidor/sida5/

## Publicera
1. Skapa ett nytt GitHub-repository med namnet `qr-sidor`.
2. Ladda upp innehållet i denna mapp till repositoryt.
3. Gå till Settings → Pages.
4. Under Build and deployment, välj `Deploy from a branch`.
5. Välj branch `main` och mappen `/ (root)`.
6. Spara.

QR-koderna i mappen `qr-koder` pekar redan på adresserna ovan.
